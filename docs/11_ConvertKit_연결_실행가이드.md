# ConvertKit 연결 · 30분 실행 가이드

> 2026-10-02 · 격주 뉴스레터 발송을 위한 ConvertKit 계정 생성·설정·사이트 연결.
> 역할 구분: **목사님** = 계정 생성·비밀번호·발신 설정 (저희가 못 함) · **저희** = 사이트 폼 삽입·DNS 레코드 안내·환영 이메일 원고.

---

## 전체 흐름 한눈에

```
① 목사님 · 가입 (5분)              → ConvertKit 계정
② 목사님 · 발신인 설정 (5분)         → From Name · From Email
③ 함께 · 발신 도메인 인증 (10분)    → DKIM·SPF 레코드 DNS 추가
④ 목사님 · 구독 양식 생성 (5분)      → Form ID 저희에게 전달
⑤ 저희 · 사이트에 폼 삽입 (저희 작업) → nanuriweb.com 하단 CTA
⑥ 함께 · 환영 이메일 설정 (5분)     → 자동 발송 켜기
⑦ 함께 · 테스트 발송 (5분)          → 본인 이메일로 Vol. 0 테스트
                     ──────────
                     총 **약 35분**
```

## ① 목사님 · 가입 (5분)

1. **convertkit.com** 접속 (지금은 "**Kit**" 로 리브랜딩됨 — 같은 서비스)
2. 오른쪽 상단 **"Sign up free"** 클릭
3. 이메일: **pastor@ijiguchon.org** 로 가입
4. 비밀번호: **16자 이상 랜덤** (암호 관리자 자동 생성 추천)
5. 플랜 선택: **"Creator (Free)"** — 최대 1,000명 구독자 무료
6. 간단한 질문 몇 개 ("무엇을 만드시나요?" → "**Newsletter about hospitable websites for Korean churches**" 같은 짧은 답)

**확인**: 가입 완료 후 대시보드가 열리면 ①번 끝.

## ② 목사님 · 발신인 설정 (5분)

대시보드 왼쪽 메뉴 → **"Settings"** → **"Email"** 탭

| 필드 | 입력 값 |
|---|---|
| From Name | `김성수 (NanuriWeb)` |
| From Email | `pastor@ijiguchon.org` |
| Reply-To Email | `pastor@ijiguchon.org` |
| Default Subject | (비워 두기 — 매 호마다 다름) |

**저장 (Save)** 누르기.

## ③ 함께 · 발신 도메인 인증 (10분) ★ 가장 중요

**왜 중요한가**: 인증 없이 보내면 메일이 **스팸함**으로 가거나 **"ijiguchon.org via convertkit-mail.com"** 처럼 어색하게 표시됩니다. 인증하면 깔끔하게 **"김성수 ⟨pastor@ijiguchon.org⟩"** 로.

### 3-1. ConvertKit 에서 DNS 레코드 발급받기

Settings → Email → **"Authenticate ijiguchon.org"** 버튼 클릭 →
화면에 나타나는 **3개 레코드**를 그대로 복사해 저에게 보내 주십시오. 양식:

```
--- 1. CNAME (DKIM 1) ---
이름 (Name/Host): [화면 값]
값 (Value/Target): [화면 값]

--- 2. CNAME (DKIM 2) ---
이름: [화면 값]
값: [화면 값]

--- 3. TXT (SPF 또는 DMARC) ---
이름: [화면 값]
값: [화면 값]
```

### 3-2. 저희가 DNS 에 추가 (nanuriweb.com → ijiguchon.org DNS)

**ijiguchon.org 의 DNS 를 어디서 관리하시는지** 알려 주시면 저희가 안내해 드립니다.
- **Vercel** → 저희가 지금 nanuriweb.com 을 올려 두는 곳. ijiguchon.org 도 Vercel 이면 저희가 직접 추가 가능.
- **Namecheap · Cloudflare · GoDaddy** → 로그인 정보가 저희에게 없어 **목사님께 화면을 공유 받으며 함께 추가**.

레코드 추가 뒤 **4–24시간**이면 전파. ConvertKit 가 "Verified ✓" 로 바뀝니다.

## ④ 목사님 · 구독 양식 생성 (5분)

대시보드 왼쪽 메뉴 → **"Grow"** → **"Landing Pages & Forms"** → **"New"** → **"Form"**

1. 양식 형태: **"Inline"** (사이트 안에 끼워 넣는 형식)
2. 템플릿: 가장 **단순한 것** (이름·텍스트만 있는 양식)
3. 설정:
   - **Form Name**: `NanuriWeb Biweekly Letter`
   - **Fields**: **Email 만**. 이름·전화·교회 모두 **삭제** (부담 낮춤)
   - **Button Text**: `구독하기`
   - **Success Message**: `환영합니다. 첫 편지는 격주 수요일에 보내 드립니다. 받은편지함을 확인해 주십시오 (스팸함도 가끔).`
4. 저장 후 **"Embed"** → **"HTML"** 탭에서 코드 복사
5. 그 코드 전체를 저에게 보내 주십시오. (코드 안에 **Form ID** 가 들어 있어 저희가 사이트에 심을 때 사용)

## ⑤ 저희 · 사이트에 폼 삽입 (저희 작업)

목사님께서 ④번 코드를 보내 주시면 저희가 다음을 반영합니다 (`index.src.html` 수정 → `build.py` → 배포):

- 사이트 하단 CTA 밴드 위에 **얇은 배너**:
  ```
  환대의 홈페이지를 만드는 이야기 · 격주 1회 · 이메일 하나면 충분합니다
  [이메일 입력]  [구독하기]
  언제든 한 번의 클릭으로 멈추실 수 있습니다.
  ```
- i18n 3 언어 (ko/en/es) 동기화
- 배포 전 로컬 미리보기 → 목사님 승인 → 배포

**예상 작업 시간**: 저희 쪽 1시간 내외.

## ⑥ 함께 · 환영 이메일 설정 (5분)

ConvertKit → **Automations** → **"New Automation"** → **"When a subscriber joins NanuriWeb Biweekly Letter form"**

→ **"Then · Send Email"** → 아래 원고 그대로 복사·붙여넣기:

### 환영 이메일 원고

**제목**: 환영합니다 — 첫 편지는 격주 수요일에

**본문**:
```
안녕하십니까.
NanuriWeb 김성수 목사입니다. 시애틀지구촌교회를 담임하고 있습니다.

NanuriWeb 격주 편지를 구독해 주셔서 감사드립니다.

이 편지는 **격주 수요일 오전**에 짧게 한 통씩 도착합니다. 영업 메일이 아니라, 홈페이지를 만드는 자리에서 저희가 만난 작은 장면과 질문을 담은 조용한 편지입니다. 평균 500자 안. 1분이면 읽으십니다.

지금 당장 홈페이지가 필요하지 않으셔도 좋습니다. 그저 어느 수요일에 이 편지가 반가우시면 저희에게 그보다 큰 선물이 없습니다.

이 편지가 더는 반갑지 않으시면 어느 때든 하단의 "구독 해지" 한 번으로 조용히 멈추실 수 있습니다.

김성수 드림
NanuriWeb 대표 · 시애틀지구촌교회 담임목사
Hebron Platform LLC (Washington State)
pastor@ijiguchon.org
nanuriweb.com
```

→ **"Save and Publish"** 눌러 자동 발송 켜기.

## ⑦ 함께 · 테스트 발송 (5분)

### 7-1. 저희 폼으로 구독 테스트
사이트에 폼이 올라간 뒤, **목사님 다른 이메일** (Gmail 등) 로 가서 폼에 그 주소를 입력 → "구독하기".

### 7-2. 환영 이메일 수신 확인
30초 안에 환영 이메일이 그 Gmail 로 도착하는지 확인. 받은편지함·스팸함 둘 다 확인.

### 7-3. 첫 호 (Vol. 1) 테스트 발송
ConvertKit → **"Broadcasts"** → **"New Broadcast"**

- Subject: `NanuriWeb · 로고 없이 시작한 교회`
- Body: `operations/biweekly-newsletter/files/newsletter-template.md` 의 **첫 호 샘플** HTML 그대로 붙여넣기
- **Send Preview** 로 목사님 이메일 2개 (ijiguchon · gmail) 에 각각 테스트
- 모바일·PC에서 모두 깨짐 없이 보이는지 확인
- **스팸함으로 가지 않는지** 확인 (DKIM 인증이 되어 있으면 받은편지함)

이상 없으면 **공식 발송 준비 완료**.

## 저희에게 알려 주실 세 가지 (ConvertKit 가입 뒤)

1. **②번 완료** — "발신인 설정 저장했습니다" 한 줄
2. **③번 DNS 레코드 3개** — ConvertKit 화면에서 복사한 값 그대로
3. **④번 Embed HTML 코드** — 복사한 전체 (Form ID 포함)

이 셋을 받으면 저희가 **24시간 안에** 사이트 폼 삽입·DNS 안내·환영 이메일 설정·테스트 발송까지 완료해 드립니다.

## 금지 (사고 방지)

- ❌ **ConvertKit 로그인 정보 (이메일·비밀번호) 저에게 공유 금지** — 목사님 소유 계정으로 유지
- ❌ **DKIM 레코드를 공개 저장소 (git) 에 커밋 금지** — 저에게 보내실 때도 이 문서가 아니라 **개인 메모**에
- ❌ **구독 안 하신 분을 임의 추가 금지** — CAN-SPAM 법 위반
- ❌ **ConvertKit 무료 플랜 1,000명 넘기 전 유료 전환 금지** — 1,000명 넘을 때 그때 판단
