## 템플릿 확장 단계 (2026-09-17 결정)

30종을 한꺼번에 만들지 않습니다. 관리·품질·시장 반응을 살피며 늘려 갑니다.

- **1단계 · 10종 (지금)**: 구성 10가지 각 대표 톤 하나씩. 시장에 먼저 보여 드리는 최소 완성 세트.
- **2단계 · 20종**: 각 구성의 다른 톤 추가. 1단계 반응·계약이 있으면 진행.
- **3단계 · 30종**: 카테고리별 특화 구성 추가 (교회 전용·사업체 전용·기관 전용).

판매 자료의 문구는 "**지금 10종 · 곧 20종·30종으로 확장 예정**" 으로 통일합니다.

## 판매 흐름 한 눈에 (교회 관점)

**1단계 · 처음 만남 (5분)**
"이걸로 시작해 보시겠어요?" — `05_1페이지_소개서.md` 를 이메일·문자로 보내드림 · `church_templates/index.html` 링크 한 줄.

**2단계 · 상담 요청 (10분 통화 또는 짧은 이메일)**
"제작 문의하기" 버튼으로 도착 · `04_세일즈_스크립트.md` 의 "첫 통화 20문항" 사용 · 교회 자료(로고·사진·인사말)를 어떤 상태로 갖고 계신지 확인.

**3단계 · 견적 안내 (제안서 · 30분 미팅)**
`06_제안서_템플릿.md` 로 교회 이름·규모·특징 넣고 30분 미팅 · 10종에서 3종 추천 · 일정·가격·포함 항목 확인.

**4단계 · 계약 · 자료 받기 (7일)**
계약서 · 도메인 · 자료 폴더 · 원고 초안 대행 시작.

**5단계 · 제작 · 완성본 확인 (14일)**
초안 → 교회 확인 → 검수 → 공개.

**6단계 · 공개 이후 (매월)**
관리자 화면 사용 안내 · 담당 유지보수 계약(선택).

## "너무 어려워요" 를 없애는 세 가지 약속 (모든 자료에 반복)

1. **교회가 하실 일은 셋입니다**: 문의 → 자료 → 확인. 나머지는 저희가 합니다.
2. **자료가 다 없어도 시작합니다**: 원고 초안·기존 사이트 이관·사진이 없어도 완성해 드립니다.
3. **완성된 사이트는 교회 소유입니다**: 월 이용료로 잠기지 않습니다. NanuriWeb이 문 닫아도 사이트는 남습니다.
