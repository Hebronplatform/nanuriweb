# examples/

실제 사용에서 **상대가 답장을 주신 좋은 답장**을 저장합니다.
파일 이름: `YYYY-MM-DD-good.md`

## 저장 기준
- 상대가 **48시간 안에 답장**하신 경우 (= 답장을 끌어낸 답장)
- 또는 상대가 **"고맙습니다, 2단계로 넘어가요"** 류 호의적 반응

## 저장 양식 (복사해서 쓰기)

```markdown
# YYYY-MM-DD · [교회 이름 · 호칭]

## 상황 요약 (한 줄)
어떤 문의였는지 · 어떤 변형(샘플 A/B/C)을 썼는지

## 보낸 본문
(실제로 보낸 전체 본문 · 서명 포함)

## 상대 반응
- 답장 시간: n시간 후
- 답장 요약: …

## 이 답장이 왜 좋았는지 (한두 줄)
- …
```

처음엔 비어 있습니다. 실제 사용이 쌓이면 여기가 가장 귀한 자산이 됩니다.

## 개인정보 주의
`examples/` 는 Git 에 커밋되지 않습니다 (`.gitignore` 확인). 실제 교회명·이메일·전화번호 포함 가능하므로 이 폴더 밖으로 유출 금지.
