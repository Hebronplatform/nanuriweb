# examples/

**6개월 이상 안정적으로 운영 중인 교회의 핸드오프** 를 저장합니다 (교회가 사이트에 자신감을 가지시게 된 사례).
파일 이름: `YYYY-MM-DD-[교회이름약자].md`

## 저장 기준
- 교회가 **핸드오프 뒤 6개월 이상** 사이트를 자체 관리 중
- D+30 체크인에서 **"잘 쓰고 있습니다"** 또는 긍정적 피드백
- 큰 사고 없이 안정

## 저장 양식

```markdown
# YYYY-MM-DD · [교회 이름 약자] · 핸드오프 완료

## 교회 유형 · 유지보수 계약 여부
가정교회 / 개척 / 전통 / 이민 — 유지보수: ✓/✗

## 보낸 변형
A (유지보수) / B (미계약) / C (도메인 이관) / D (자체 IT)

## 안전 전달 방식
암호 관리자 / Signal / 전화 / One-time Secret

## D+30 체크인 응답
A (잘 쓰고 있음) / B (수정 요청) / C (응답 없음)

## 교회가 자체 관리 중인 항목
공지 / 사진 / 인사말 / 오시는 길 / 기타

## 사고·수정 이력 (6개월 사이)
- …

## 이 핸드오프가 왜 잘 됐는지 (한두 줄)
- …
```

처음엔 비어 있습니다. 6개월 안정 사례가 쌓이면 **"어떻게 핸드오프를 해야 교회가 자립하는가"** 가 명확해집니다.

## 개인정보 주의
`examples/` 는 Git 에 커밋되지 않습니다. 실제 교회명·담당자·사이트 지표 포함 가능 — 이 폴더 밖으로 유출 금지. **관리자 비밀번호·EPP 코드는 어떤 경우에도 이 폴더에 저장 금지**.
