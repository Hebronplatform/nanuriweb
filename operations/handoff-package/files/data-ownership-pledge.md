## 핸드오프 이메일 본문 삽입 (기본)

```
완성된 사이트의 모든 자료 (HTML · CSS · 이미지 · 문안 · 데이터베이스) 는 **[교회 이름] 소유** 입니다. 저희가 어떤 사유로든 서비스를 중단하는 경우, **사이트 자료 전체를 교회 도메인·서버로 인계**해 드립니다. 다른 개발사가 이어받아 관리할 수 있는 표준 구조로 만들어 두었습니다. 월 이용료로 잠기지 않습니다.
```

2. **인계 보장**: 교회가 요청하시거나, 저희 서비스가 어떤 사유로 중단되는 경우, **30일 안에** 사이트 자료 전체를 다음 형태로 인계해 드립니다:

## 왜 이 약속이 중요한가 (잊지 않기 위해)

웹 제작·호스팅 업계에서 **"사이트를 인질로 잡는" 사고**가 흔하다. 월 이용료가 밀렸다는 이유로 사이트를 폐쇄하거나, 다른 업체로 옮기려 하면 자료를 넘기지 않거나, 자체 비밀 포맷으로 만들어 다른 개발사가 이어받지 못하게 하는 사례. 저희는 **그 반대편에 선다**.

교회가 저희를 **언제든 떠날 수 있는 자유**를 보장할 때, 교회는 저희와 **더 오래 머물기를** 선택한다. 환대의 역설.

## 금지 (사고 사례 방지)

- **"저희에게 평생 맡기셔야 합니다"** 류 영업 금지
- 다른 개발사가 이해 못 할 **비밀 포맷·관리자 화면** 금지
- 교회가 자료 인계 요청하실 때 **지연·거절·조건 추가** 금지
- 월 이용료 미납을 이유로 사이트 **삭제·접근 차단** 금지 (유지보수 중단은 가능하되 자료 접근은 유지)
