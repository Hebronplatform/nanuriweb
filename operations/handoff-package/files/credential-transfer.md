## 안전 전달 방식 (추천 순)

### 1️⃣ 암호 관리자 공유 링크 (최우선 · 추천)
- **1Password · Bitwarden · Dashlane** 중 저희 계정에서 **"Secure Share"** 또는 **"Send"** 기능 사용
- 담당자 이메일로 **일회성 열람 링크** 발송
- 설정: **24시간 뒤 자동 만료** · **1회 열람 후 삭제**
- 담당자가 열람하면 저희에게 알림 → 열람 확인

### 2️⃣ Signal (암호화 메신저)
- 담당자의 Signal 번호가 있으시면 Signal 로 전송
- **"사라지는 메시지"** 설정 (24시간)
- 읽음 확인 뒤 저희 쪽에서도 삭제

### 3️⃣ 전화 (가장 안전하지만 비효율)
- 담당자가 받으실 수 있는 시간에 전화
- 비밀번호를 **구두로** 읽어 드림
- 전화 끝나면 즉시 **다른 비밀번호로 바꾸시도록** 안내

### 4️⃣ One-time Secret 서비스 (저희 서버 외부 사용)
- **1ty.me · onetimesecret.com · PrivateBin** 등 일회성 링크 생성
- 담당자 이메일로 링크만 전송
- **열람 즉시 자동 삭제**
- 서비스 선택 전 담당자가 **그 서비스 신뢰 가능한지** 짧게 안내

## 금지 (사고 사례 방지)

- ❌ **이메일 본문에 비밀번호 평문**
- ❌ **이메일 제목에 비밀번호**
- ❌ **같은 이메일에 아이디·비밀번호 함께 송부** (분리하면 피해 축소)
- ❌ **같은 비밀번호를 여러 교회에 재사용**
- ❌ **SMS로 긴 비밀번호 전송** (문자 기록 보관 위험)
- ❌ **공개 Google Drive 문서에 비밀번호 저장**
- ❌ 비밀번호를 **쉽게 예측 가능한 조합**으로 생성 (교회이름+1234 등) · **16자 이상 랜덤**

## 전달 체크리스트

- [ ] 비밀번호가 **16자 이상 랜덤** (암호 관리자 자동 생성)
- [ ] 안전 채널 (암호 관리자 공유 / Signal / 전화 / One-time Secret) 중 **하나만** 선택
- [ ] 담당자에게 **"첫 로그인 시 비밀번호를 바꿔 주십시오"** 안내 명시
- [ ] 2FA (이중 인증) 설정 안내 — 가능하면 교회가 자체 설정하시도록 짧은 영상
- [ ] 저희 쪽 **임시 비밀번호 기록은 즉시 삭제**
- [ ] 담당자가 **열람·수신 확인**된 뒤에만 핸드오프 완료 처리

## 도메인 이관 패키지 (교회가 도메인·DNS 를 교회 쪽에서 관리하길 원하실 때)

**이관이 필요한 자료 (저희가 담당자에게 전달)**
- 도메인 등록 업체 (Namecheap · Cloudflare · GoDaddy 등)
- 계정 이메일
- **EPP 코드 (Authorization Code)** — 60자 이상 랜덤 · 도메인 이관의 비밀번호 역할
- 현재 DNS 레코드 전체 (A · CNAME · MX · TXT · SPF · DKIM · DMARC)
- 호스팅 서버 (Vercel · Netlify · Cloudflare Pages 중 어느 쪽인지)
- SSL 인증서 상태 (대부분 자동 갱신)
- 백업 파일 (전체 사이트 · ZIP · 3GB 이내)

**이관 순서**
1. 교회가 새 도메인 등록 업체 계정 생성
2. 저희가 현재 등록 업체에서 **"이관 잠금 해제" + "EPP 코드 발급"**
3. EPP 코드를 **안전 채널**로 담당자에게 전달
4. 담당자가 새 업체에서 "**도메인 이관 요청**" 입력
5. 5–7일 뒤 이관 완료 — 이 사이에 DNS 가 끊기지 않도록 **TTL 60초로 임시 설정**

**금지**
- EPP 코드를 **이메일 평문**으로 보내기 — 도메인 탈취 사고 우려
- 이관 중 **DNS 레코드를 미리 삭제** — 사이트 다운 사고

## 자료 이관 (교회가 사이트 전체를 다른 업체에서 운영하길 원하실 때)

- 전체 소스 (HTML · CSS · JS · 이미지) **ZIP 패키지**
- 데이터베이스 백업 (관리자 화면 데이터) **SQL dump**
- README 파일 — 다른 개발사가 이어받을 때 **"어디서부터 보시면 되는지"** 안내
- 사용된 외부 서비스 리스트 (HebronGuide 등재 유지 여부 · 결제업체 · 이메일 서비스 등)

전달은 **Google Drive 공유 폴더** (`onboarding-pack` 과 동일 방식) 로. ZIP 파일은 폴더에 올리고, 암호 관리자로 **접근 권한만** 공유.
