# files/admin-walkthrough-videos.md · 짧은 영상 세 개 스크립트

> **원칙**: 각 2–3분. **담임목사·사무장이 폰으로 보면서 따라할 수 있을 만큼** 단순하게.
> 녹화 도구: Loom · OBS · QuickTime 중 교회가 가장 쉽게 열람 가능한 플랫폼 (YouTube 미공개 링크 추천).
> 매 교회에 **재사용 가능** — 교회 이름이 영상 안에 나오지 않는 **범용 화면**으로 녹화.

---

## 영상 1 · 공지·주보 올리기 (2–3분)

**장면 흐름**
1. 관리자 화면 로그인 (아이디 입력 → 비밀번호 입력 → 로그인 버튼)
2. 왼쪽 메뉴에서 "**공지사항**" 클릭
3. 오른쪽 상단 "**+ 새 공지 올리기**" 버튼
4. 제목 입력 (예: "주일 2부 예배 시간 변경 안내")
5. 본문 입력 (화면 안 에디터 간단 설명 — 굵게·링크 정도만)
6. 날짜 자동 입력 확인
7. "**게시**" 버튼
8. 홈페이지 새로고침 → **공지가 바로 보임**
9. 오타 수정 — 공지 목록에서 해당 항목 클릭 → "**수정**" → 저장
10. 공지 삭제 — 공지 목록에서 해당 항목 → "**휴지통**" → 확인

**녹화 멘트 (한 문단)**
> "안녕하세요, NanuriWeb 입니다. 지금부터 교회 홈페이지에 공지를 올리는 법을 보여 드리겠습니다. 왼쪽 메뉴에서 공지사항을 누르시고, 오른쪽 위 '새 공지 올리기' 버튼을 누르시면 됩니다. 제목과 본문만 쓰시면 날짜는 자동으로 들어갑니다. 게시 버튼을 누르시면 홈페이지에 바로 보입니다. 수정이나 삭제도 같은 방식입니다. 어려우시면 저희에게 이메일 주시면 됩니다."

## 영상 2 · 사진 올리기 (앨범) (2–3분)

**장면 흐름**
1. 관리자 화면 로그인
2. 왼쪽 메뉴에서 "**사진·앨범**" 클릭
3. "**+ 새 앨범 만들기**"
4. 앨범 이름 입력 (예: "2026 가을 전교인 야유회")
5. 날짜 선택
6. **사진 끌어다 놓기** (최대 20장 한 번에)
7. 업로드 진행 바
8. 사진 **순서 바꾸기** (끌어서 이동)
9. 사진 **삭제** (각 사진 X 버튼)
10. "**게시**" 버튼
11. 홈페이지 새로고침 → **앨범이 바로 보임**
12. **중요 안내**: 성도 얼굴이 나오는 사진은 **반드시 성도 동의 후** 올리기. 아이는 부모님 동의.

**녹화 멘트**
> "앨범을 만들고 사진을 올리는 방법입니다. 앨범 이름을 쓰시고, 사진을 끌어다 놓으시면 됩니다. 성도님 얼굴이 나오는 사진은 꼭 미리 동의를 받으시고 올려 주십시오. 어린이는 부모님께 꼭 여쭤 주십시오. 사진을 올린 뒤에도 순서를 바꾸거나 하나씩 지우실 수 있습니다. 게시 버튼을 누르시면 홈페이지에 바로 보입니다."

## 영상 3 · 인사말·오시는 길 수정하기 (2–3분)

**장면 흐름**
1. 관리자 화면 로그인
2. 왼쪽 메뉴에서 "**페이지 관리**" 클릭
3. 목록에서 "**담임목사 인사말**" 클릭
4. 본문 편집 (문단 수정 · 저장)
5. 홈페이지 새로고침 → **인사말이 바뀜**
6. 뒤로 가기 → "**오시는 길**" 클릭
7. 주소 수정 (예: 사무실 이사)
8. 지도 미리보기 자동 갱신
9. 저장
10. 홈페이지 새로고침 → **주소가 바뀜**
11. **중요 안내**: 큰 변경(새 페이지 만들기 · 디자인 바꾸기) 은 저희에게 부탁해 주시면 됩니다.

**녹화 멘트**
> "담임목사 인사말이나 오시는 길 안내를 바꾸시는 법입니다. 페이지 관리에서 바꾸고 싶으신 페이지를 누르시고, 본문을 수정하신 뒤 저장만 누르시면 됩니다. 홈페이지에 바로 반영됩니다. 큰 변경은 저희에게 부탁해 주셔도 됩니다. 작은 수정은 교회가 직접 하실 수 있도록 만들어 두었습니다."

## 영상 녹화 체크리스트

- [ ] **범용 화면** 으로 녹화 (교회 이름·실제 성도 사진 노출 없이)
- [ ] 각 영상 **3분 이내**
- [ ] 자막 (한글) — 폰에서 소리 못 들으시는 분을 위해
- [ ] 음성 **또렷**하게 (주변 소음 없는 공간)
- [ ] 커서가 **느리게** 이동 (따라오실 수 있게)
- [ ] 영상 마지막에 **"어려우시면 이메일 주십시오"** 한 문장
- [ ] YouTube **미공개 (Unlisted)** 로 업로드 — 교회에만 링크 공유
- [ ] 링크를 `handoff-email.md` 자리표시자에 삽입

## 추가 영상 (선택)

### 긴 영상 · 관리자 화면 전체 투어 (15–20분)
- 모든 메뉴 한 번씩 돌아보기
- 자주 쓰시지 않는 기능까지 (설정 · 사용자 추가 · 데이터 내보내기 · 백업)
- 자체 사무장·IT 담당이 있는 교회를 위한 선택 자료
