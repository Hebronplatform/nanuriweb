> **원칙**: 교회가 사고 상황에서 **어디로 연락해야 할지 1초 안에 알 수 있도록**.
> 저희의 응답 시간대는 **정직하게** 표시 (24시간 응답 가능하지 않다면 그렇게 쓰기).

## 핸드오프 이메일 본문 삽입 (기본)

```
## 긴급 상황에는

사이트가 열리지 않거나 · 결제·DNS 사고가 의심되거나 · 보안 문제가 있어 보이면 **즉시** 아래로 연락 주십시오.

- **이메일**: pastor@ijiguchon.org (평일 24시간 안)
- **전화**: [목사님 긴급 전화 번호] (평일 09:00–21:00 Pacific Time)
- **메신저**: [카카오톡·Signal 등 — 교회가 쓰시는 것으로]

**응답 시간 안내 (정직하게)**
- 평일 사이트 다운 · 결제 사고 : **1시간 안**
- 평일 일반 문의 : **24시간 안**
- 주말·공휴일 : **다음 평일 아침**
- 긴급 전화 가능 시간 외 : 이메일로 남기시면 가능한 가장 빠른 시간에 연락
```

## 긴급 상황 분류별 대응 매뉴얼 (저희 내부용)

### 🔴 Level 1 · 즉시 (1시간 안 응답)
- 사이트 전체 다운 (`https://[도메인]` 접속 불가)
- SSL 인증서 만료 알림 (브라우저 "안전하지 않음" 경고)
- 온라인 헌금 결제 실패 반복
- 보안 침해 의심 (관리자 비밀번호 변경 안 됨 · 알 수 없는 로그인)
- DNS 레코드 변조 의심

**대응**: 즉시 사이트 상태 확인 → 교회에 연락 → 로그 수집 → 복구

### 🟡 Level 2 · 당일 (24시간 안 응답)
- 특정 페이지만 안 열림
- 사진 업로드 실패
- 공지 올렸는데 반영 안 됨
- 모바일에서만 레이아웃 깨짐
- 검색 등록 문제

**대응**: 당일 재현 테스트 → 수정 → 교회 확인 요청

### 🟢 Level 3 · 일반 (며칠 안)
- 디자인 수정 요청
- 새 페이지 추가
- 사용법 질문
- 성능 최적화

**대응**: 유지보수 계약 범위에서 처리 · 미계약시 건당 견적

## 교회에 안내할 사고 신고 양식 (이메일 서브젝트 템플릿)

```
[긴급] [교회 이름] 홈페이지 - [어떤 사고]

예:
[긴급] 새순교회 홈페이지 - 접속 안 됨
[긴급] 샘물교회 - 헌금 결제 오류
[긴급] 베들레헴교회 - 관리자 로그인 안 됨
```

이 양식을 교회에 **미리 알려 드려서** 사고 시 즉시 쓰시도록. 이메일 제목에 **[긴급]** 이 있으면 저희 알림 설정이 다름.

---

## 저희가 할 수 없는 것 (정직하게 미리 안내)

- **24/7 즉시 응답** — 저희는 2인 체제가 아닙니다. 평일 응답이 최선입니다.
- **다른 업체 서비스 사고 복구** — Google · Tithe.ly · HebronGuide 같은 외부 서비스 사고는 저희가 복구하지 않습니다. 저희는 **연락 창구**가 되어 드리되, 수리는 그 서비스가 합니다.
- **교회 쪽에서 비밀번호를 분실하신 경우의 즉시 복구** — 2FA 백업 코드가 없으시면 몇 시간이 걸릴 수 있습니다. **2FA 설정 시 백업 코드를 안전한 곳에 보관** 하시도록 핸드오프 때 안내.
- **24시간 모니터링** — 유지보수 계약 상품에서도 "자동 알림" 수준이지, 사람이 지켜보고 있지는 않습니다.

이런 한계를 미리 밝혀 두면 교회가 **"왜 전화 안 받으세요"** 라고 서운해 하시는 사고가 줄어듭니다.
