# files/upload-folder-guide.md · 공유 폴더 생성·공유 안내

> **원칙**: Google Drive 우선 (교회가 가장 많이 쓰는 도구). 교회가 다른 도구를 원하시면 Dropbox · OneDrive 로 조정.
> **보안**: 담당자 이메일에만 "편집자" 권한. "링크로 누구나" 금지.

---

## 생성 순서 (매 교회마다)

1. Google Drive 에서 새 폴더 생성: 이름 **"[교회 이름] · NanuriWeb 자료"**
2. 폴더 안에 **하위 폴더 4개** 만들기:
   - `01_로고` — 로고 파일 (가능하면 .ai · .svg · .png 순)
   - `02_사진` — 예배당 · 행사 · 담임목사 · 공동체 사진
   - `03_원고` — 인사말 · 교회 소개 · 처음 오시나요 등 모든 글
   - `04_기타` — 501(c)(3) 사본 · 기존 홈페이지 자료 · 그 밖
3. 담당자 이메일에 **"편집자" 권한** 부여 (알림 메일 발송)
4. 생성한 폴더 링크를 **반드시 다른 브라우저**에서 테스트 — 담당자 입장에서 열리는지 확인
5. 링크를 `onboarding-email.md` 본문의 `[Google Drive 공유 폴더 링크]` 자리에 삽입

---

## 금지 (사고 방지)

- **"링크로 누구나 보기"** 설정 금지 — 담당자 이메일에만 직접 공유
- 다른 교회의 폴더 링크를 섞어 쓰지 않기 — 교회당 **새 폴더** 생성
- 폴더 안에 **다른 교회 자료** 가 있지 않은지 생성 직후 다시 확인
- 담당자 이메일 **오타 금지** — 상담 메모의 이메일을 ctrl+c · ctrl+v 로

---

## 교회가 다른 도구를 원하실 때

| 도구 | 공유 방식 | 장점 |
|---|---|---|
| **Dropbox** | 폴더 공유 · 담당자 이메일 초대 | 교회 직원이 이미 Dropbox 쓰시면 익숙 |
| **OneDrive** | SharePoint 폴더 공유 | 교회가 Microsoft 365 를 쓰시면 자연 |
| **WeTransfer** (일회성) | 링크 1회 발송 | 자료가 소수 (3–5개) 일 때 간단 |
| **이메일 첨부** | 담당자가 메일로 전송 | 자료가 폰 사진 몇 장일 때 |

**원칙은 같다**: 교회가 **가장 편한 방식**으로. 저희 편의가 아니라.

## 폴더 생성 뒤 담당자에게 보낼 안내 (이메일 안 삽입)

```
자료 올리실 폴더를 열어 두었습니다. 아래 네 하위 폴더 중 **있는 것부터** 올려 주시면 됩니다.

- 01_로고 — 로고 파일
- 02_사진 — 예배당·행사·담임목사·공동체
- 03_원고 — 인사말·교회 소개 등 모든 글
- 04_기타 — 501(c)(3) 사본·기존 홈페이지 자료 등

폰에서 바로 올리셔도 되고, 양식·크기 제한은 없습니다. 올려 주실 때마다 저희에게 자동으로 알림이 갑니다.

[Google Drive 공유 폴더 링크]
```
