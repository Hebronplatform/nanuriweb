# examples/

**교회가 자료를 성공적으로 완성한 온보딩** 을 저장합니다 (자료 지연 없이 공개일에 공개된 사례).
파일 이름: `YYYY-MM-DD-[교회이름약자].md`

## 저장 기준
- 교회가 **공개 2–3일 전까지 자료를 완성** 하신 경우
- 또는 교회가 **"이 안내가 정말 도움됐다"** 류 피드백을 주신 경우

## 저장 양식

```markdown
# YYYY-MM-DD · [교회 이름 약자] · 온보딩 성공

## 교회 유형 · 자료 상태 (처음)
가정교회 / 개척 / 전통 / 이민 — 자료 상태: 로고 ✓ · 사진 ✗ · 원고 ✗

## 보낸 변형
A (다 준비됨) / B (급함) / C (자체 디자이너) / 기본

## 사용한 인사말 초안
유형 A/B/C/D 중 어느 것

## 교회 반응 · 자료 도착까지 걸린 시간
- 자료 도착 n일 (목표 D-12 중)
- 담당자가 특히 좋아하신 안내:

## 이 온보딩이 왜 좋았는지 (한두 줄)
- …
```

처음엔 비어 있습니다. 공개 사례가 쌓이면 **"어떤 안내가 자료를 끌어오는가"** 가 명확해집니다.

## 개인정보 주의
`examples/` 는 Git 에 커밋되지 않습니다. 실제 교회명·담당자 이메일·공유 폴더 링크 포함 가능 — 이 폴더 밖으로 유출 금지.
