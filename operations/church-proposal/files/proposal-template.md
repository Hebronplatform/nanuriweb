## 4. 2주 일정 (문의부터 공개까지)

```
| 단계 | 걸리는 시간 | 누가 |
|---|---|---|
| 문의 · 견적 · 계약 | 3–5일 | 함께 |
| 자료 정리 | 1–2일 | 교회 |
| 초안 제작 | 5–7일 | 저희 |
| 완성본 확인 | 2–3일 | 교회 |
| 검수 · 공개 | 2일 | 저희 |
| **합계** | **2주 내외** | |

급하실 경우 축소 일정으로 조정해 드립니다 (최소 10일).
```

---

## 5. 교회가 하실 일은 셋입니다

```
1. **문의** (5분) — 이메일 한 통 (이미 하셨습니다)
2. **자료** (1–2일) — 로고·사진 몇 장·인사말 초고. 없으셔도 저희가 초안 대행
3. **확인** (30분) — 완성본 미리보기 링크에서 고칠 곳 말씀

나머지는 저희가 합니다: 원고 초안·사진 보정·4가지 화면 폭 검수·도메인 연결·SSL·검색엔진 기본 설정·관리자 화면 사용 안내 (짧은 영상 3개).
```
