# examples/

**계약으로 이어진 제안서** 를 저장합니다 (이사·재정부 설득에 효과가 입증된 것).
파일 이름: `YYYY-MM-DD-[교회이름약자].md`

## 저장 기준
- 교회가 **제안서 받은 뒤 2주 안에 계약** 한 경우
- 또는 교회가 **"잘 썼다 · 이사회가 바로 통과했다"** 류 피드백을 주신 경우

## 저장 양식 (복사해서 쓰기)

```markdown
# YYYY-MM-DD · [교회 이름 약자] · [상품명] 계약

## 상황 요약 (한 줄)
성도 규모 · 자료 상태 · 특별 요청

## 추천한 디자인 3종
- 1️⃣ [번호] [이름] — 왜
- 2️⃣ [번호] [이름] — 왜
- 3️⃣ [번호] [이름] — 왜

## 추천한 상품
[Essential / Standard / Premium] — 이유

## 제안서 본문
(전체 본문 그대로 · 자리표시자는 모두 채워진 상태)

## 교회 반응 · 계약까지 걸린 시간
- 제안서 받은 뒤 n일 후 계약
- 결정 과정에서 교회가 특히 언급한 것:

## 이 제안서가 왜 통했는지 (한두 줄)
- …
```

처음엔 비어 있습니다. 계약 사례가 하나씩 쌓이면 **이 폴더가 가장 귀한 영업 자산**이 됩니다.

## 개인정보 주의
`examples/` 는 Git 에 커밋되지 않습니다 (`.gitignore` 확인 필요). 실제 교회명·연락·가격 할인 조건 포함 가능. 이 폴더 밖으로 유출 금지.
