# files/subscriber-management.md · ConvertKit 구독자 관리

> **원칙**: 도구는 **ConvertKit** 우선 (최대 1,000명 무료 · 뉴스레터 UI 좋음 · 자동화 강함).
> 다른 도구로 바꾸시려면 이 파일 먼저 수정.

---

## ConvertKit 계정 설정 (최초 1회)

1. convertkit.com 가입 (목사님 계정 — 저희가 다루지 않음)
2. **"Creator"** 플랜 선택 (1,000명까지 무료)
3. **발신 도메인 인증**: `nanuriweb.com` DNS 에 DKIM·SPF 레코드 추가 (저희가 안내)
4. **발신인 설정**:
   - From Name: `김성수 (NanuriWeb)`
   - From Email: `pastor@ijiguchon.org`
   - Reply-To: `pastor@ijiguchon.org`
5. **구독자 양식** (Form) 하나 생성:
   - 이름: "**NanuriWeb 격주 편지**"
   - 필드: 이메일 **하나만**. 이름·교회·전화 요청 X (부담 낮춤).
   - 양식 끝 문구: "격주 1회 · 이메일 하나면 충분합니다 · 한 번의 클릭으로 멈추실 수 있습니다"
6. **환영 이메일 (Welcome)** 설정 — 구독 즉시 자동 발송:
   - 제목: "환영합니다 — 첫 편지는 격주 수요일에"
   - 본문: 2–3문장. 구독 감사 · 격주 수요일 발송 · 응답 환영.

## 구독자 리스트 운영 (매주)

### 매주 금요일 저녁 (5분)
- ConvertKit 대시보드 열어 **지난주 새 구독자 수** 확인
- 구독 해지한 분이 있으면 **이유 묻지 않음** · 그냥 보냄
- 새 구독자 중 **답장 주신 분**이 계시면 하루 안에 짧은 답장

### 매 발송 뒤 (매 2주)
- 발송된 호의 **열람률 · 클릭률** 기록 → `notes.md`
- 열람률이 평균보다 20% 이상 낮으면 → 제목·발송 시간 재검토
- 클릭 (답장 이메일) 받으면 → 하루 안에 응답

### 분기 1회 (3개월마다)
- **90일간 열지 않은 구독자** 확인
- 재참여 캠페인 **보내지 않음** · 조용히 둠 (스팸으로 느껴지지 않도록)
- 180일 이상 안 열면 리스트에서 **조용히 제거** (ConvertKit "Cold Subscribers" 자동 정리)

## 세그먼트 (구독자 분류 · 선택)

구독자 수 100명 넘으면 가볍게 시작.

| 세그먼트 | 기준 | 왜 |
|---|---|---|
| **상담 전** | 아직 nanuriweb.com 상담 폼을 안 보내신 분 | 뉴스레터만 받으시며 지켜보시는 분 |
| **상담 중** | 상담 메일을 저희와 주고받고 계신 분 | 한창 결정 중이시므로 뉴스레터가 더 중요 |
| **계약 뒤** | 사이트 제작 중 또는 공개 후 | 뉴스레터 톤 조금 바꿀 수 있음 (파트너 느낌) |

세그먼트별로 **다른 뉴스레터**를 보내지 않음 — 같은 본문. 다만 **구독 해지 사유 추적** 에 도움.

## 발송 시간

- **격주 수요일 오전 9시 Pacific Time** 기본
- 북미 동부 (ET) 는 정오 · 서부 (PT) 는 아침 — 담임목사님이 메일 여실 시간
- 공휴일·주요 교회 절기 (성탄 · 부활절 전주) 는 **하루 당기거나 연기**

## 발송 전 체크리스트 (매번)

- [ ] 제목이 15자 이내 · 낚시 X
- [ ] 본문 500자 이내 (글자 수 세기)
- [ ] 구독 해지 링크 작동 (브라우저로 테스트)
- [ ] HebronGuide 1문장 들어 있음
- [ ] 저희 이메일(`pastor@ijiguchon.org`) 받은편지함에 **테스트 발송** 하여 모바일·PC 양쪽 확인
- [ ] 익명 처리 다시 확인 (교회 추측 가능하지 않은지)

## 금지 (사고 사례)

- ❌ 구독 안 하신 분에게 **임의 추가 금지** (CAN-SPAM 법 위반 · 신뢰 손상)
- ❌ 리스트를 **다른 업체·서비스에 공유 금지**
- ❌ 구독 해지 어렵게 만들기 (**원 클릭** 보장)
- ❌ 홍보 메일 보내면서 "**뉴스레터**" 라고 속이기
- ❌ A/B 테스트에서 **낚시 제목이 열람률 높다고 사용**

## 지표 기록 양식 (매 발송 뒤 `notes.md` 에)

```
Vol. N (YYYY-MM-DD)
- 제목: [제목]
- 에피소드 출처: [어느 폴더·어느 상담]
- 발송 수: nnn
- 열람률: nn% (평균 대비 ±n%)
- 클릭률: n% (답장 n건)
- 메모: [의외의 반응·향후 메모]
```

12 호 (6개월) 쌓이면 **"어떤 제목·어떤 에피소드가 열리는가"** 가 명확해집니다.
