# files/episode-sources.md · 에피소드 어디서 모을까

> **원칙**: 지어내지 않는다. 모든 뉴스레터 에피소드는 **실제 지난 2주 사이 일어난 일**에서. 익명으로 쓰되, 사실은 사실대로.

---

## 에피소드 수집 루트 6가지

### 1. 각 폴더의 `notes.md`
가장 중요한 광맥.
- `../church-intake-reply/notes.md` — 첫 답장에서 생긴 수정·학습
- `../church-proposal/notes.md` — 제안서에서 교회가 멈춰 서신 지점
- `../onboarding-pack/notes.md` — 자료 수집 중 의외의 발견
- `../handoff-package/notes.md` — 공개 뒤 사고·수습

### 2. 각 폴더의 `examples/`
좋은 결과 뒤에 숨은 장면.
- 상담 48시간 안에 답장 주신 분의 **한 줄**
- 계약으로 이어진 제안서에서 **교회가 가장 많이 언급한 섹션**
- 자료가 하나도 없는데 공개까지 간 교회의 **첫 걸음**

### 3. 실제 상담 메모 (암호화된 저장소)
- 통화 20문항 중 **의외의 답변**
- 통화 끝에 교회가 던지신 **마지막 질문**
- 교회가 보내 주신 짧은 피드백 (D+30 체크인에서)

### 4. 자료 수집 과정의 순간
- 공유 폴더에 도착한 **첫 사진** 의 표정
- 담임목사님이 적어 보내신 **인사말 초고** 의 한 문장
- 자료가 늦게 도착했을 때 교회가 보내 주신 **설명 메일**

### 5. 사이트 공개 전후
- 공개 전날 **마지막 확인**에서 교회가 발견한 오타
- 공개 당일 **처음 들어온 트래픽**
- 공개 뒤 성도님이 보내신 **첫 반응**

### 6. 저희의 실패·수정
- 보냈다가 하루 뒤 다시 사과한 **잘못 쓴 답장**
- 가격을 잘못 안내한 뒤 **투명하게 수정한 자리**
- 사고 복구 후 **배운 것**

## 에피소드 선택 기준

### ○ 쓰기 좋은 에피소드
- **구체적 장면이 있다** (대사 · 사물 · 시간 · 장소)
- **작다** (큰 성공·큰 실패가 아니라 작은 결정)
- **보편적이다** (다른 교회·다른 담임도 공감하실 수 있는 자리)
- **당사자가 흔쾌히 익명으로 소개 되어도 좋을 것** (저희의 자체 판단보다, 상대의 입장을 먼저)

### ✕ 쓰지 않는 에피소드
- **당사자가 특정될 위험** (교회명 추측 가능 · 지역·규모·목회자 성함 조합)
- **성도 갈등 · 재정 사고 · 가족 문제**
- **자랑** (수상·대규모 계약·언론 노출)
- **다른 업체를 비하하는 비교**
- **지어낸 장면** (한 번의 지어냄이 전체 신뢰를 깬다)

## 익명 처리 공식

### 교회 → 익명
- "**새순교회**" → "어느 교회"
- "**샘물교회**" → "작은 교회"
- "**베들레헴교회**" → "어느 가정교회"
- 지역·규모·설립 연도 **조합**으로 추측 가능하면 모두 흐리게

### 사람 → 익명
- 담임목사·사모·장로 등 **직책만** (성명 금지)
- 성도·새 가족은 "**어느 분**", "**한 성도님**"
- 말씀을 그대로 인용할 때는 "**어떤 분이 이렇게 말씀하셨습니다**" 로

### 사실 → 사실
- 숫자·시간·사물은 **그대로** 쓸 수 있음 (예: "로고 없이", "사진 세 장")
- 느낌·판단은 **저희 책임으로** 쓸 것 ("저희는 그 자리에서 ... 를 보았습니다")

## 에피소드 저장소 (내부용)

매번 뉴스레터를 쓰기 전에 **이 폴더 외부**의 암호화된 노트에 **에피소드 후보 목록**을 둔다. 저장 양식:

```
YYYY-MM-DD · [출처: notes.md / examples/ / 상담] · 한 줄 요약
```

예:
```
2026-10-01 · church-intake-reply/notes.md · 자료 다 있다고 하셨는데 제일 좋은 사진이 담임목사 뒷모습이었음
2026-09-28 · 상담 · 통화 끝에 "저희는 별 거 아닙니다" 라고 반복해서 말씀하심
2026-09-20 · onboarding-pack/examples · 공유 폴더에 처음 올라온 사진 1장이 간판 아니라 식탁 사진
```

이 리스트에서 **격주에 한 번** 하나를 뽑는다.
