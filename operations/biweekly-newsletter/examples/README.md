# examples/

**열람률·답장률이 좋았던 뉴스레터** 를 저장합니다 (어떤 제목·어떤 에피소드가 열리는지 패턴 파악).
파일 이름: `Vol-NN-YYYY-MM-DD.md`

## 저장 기준
- 열람률 **평균 대비 +15% 이상**
- 또는 **답장 2건 이상** (사람 수 아니라 응답 수)
- 또는 **상담 문의로 이어진 호** (뉴스레터 → 상담 연결 추적 가능)

## 저장 양식

```markdown
# Vol-NN · YYYY-MM-DD · [제목]

## 에피소드 출처
어느 폴더 / 어느 상담 / 어느 체크인

## 본문 (발송된 그대로)
(제목 · 본문 · 서명 · 푸터 전체)

## 지표
- 발송: nnn
- 열람률: nn% (평균 nn% 대비 +/-nn%)
- 클릭률: n%
- 답장: n건
- 상담 문의 연결: n건 (추적 가능하면)

## 왜 좋았는지 (가설 — 두세 줄)
- 제목이 질문 공식이어서?
- 에피소드가 "실패·고민" 쪽이어서?
- 여백이 특히 길었어서?
- 다른 요인?
```

처음엔 비어 있습니다. 12 호 (6개월) 쌓이면 **"어떤 글이 교회의 마음을 여는가"** 가 명확해집니다.
